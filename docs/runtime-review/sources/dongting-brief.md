# 洞庭山泉黑客松brief

### 洞庭山泉  企业简介

www.dtsq1998.com

洞庭山泉矿泉水集团前身创始于1998年，2005年至今是江苏包装饮用水行业龙头企业，2014年获中国包装饮用水行业前十强，2024年获中国天然矿泉水行业前十强，2024年获首批“江苏省高知名商标”称号，2025年认证长三角地区桶装水销量领先，2026年为“苏超”官方指定饮用水。

28年来，洞庭山泉集团一直坚持寻找江南天然优质水源，致力于为消费者提供优质、天然、健康的饮用水。目前，集团拥有苏州洞庭山、溧阳瓦屋山、安吉龙王山、镇江茅山等多个黄金优质水源地和生产基地。在长三角拥有多家子公司，3000多家加盟店，5000多个配送点，服务1000多万家庭和企业终端消费者。
