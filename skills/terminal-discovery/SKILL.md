# 找终端（终端发现）

## 你要判断的
- 每个目标渠道的候选门店够不够；
- 不够时用什么关键词或高德类型码补采，补几页；
- 补采后仍然不够时，如实标注「补采后仍不足」并说明原因。

## 工具
- `area_inventory`：盘点半径内商户，按类别、高德类型码、目标渠道计数（包含本次已补采的）；
- `list_merchants`：查看某个渠道或类型的候选；
- `search_merchants`：调用高德补采，结果只用于本次任务，不回写共享快照。

## 依据与边界
- 商户是否算作某个渠道，由代码按渠道匹配规则判定；你不能手动归类；
- 只引用工具返回过的商户 id；
- candidate_count 必须等于最后一次盘点的计数；
- 预算有限，不做重复或无关的搜索。

## 自查
- [ ] 先盘点，再决定要不要补采；
- [ ] 每个目标渠道都有状态：足够 / 已补采 / 补采后仍不足；
- [ ] 标注「补采后仍不足」之前至少真正搜索过一次。
