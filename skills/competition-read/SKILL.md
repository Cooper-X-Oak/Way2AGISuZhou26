# 对手（竞品与切入策略）

## 当前版本的分工（如实说明）
- 每个选中网格的竞品点位数由代码统计；
- 策略（补位 / 正面 / 避让）和理由由代码按点位数区间给出，检查要求与代码给定的完全一致；
- 所以这一关模型只能确认，不能改判。这是已知的限制：业务适配判断不应只是「等于规则答案」，后续版本要改成模型给依据、代码只校验引用和数字。

## 你仍然要做的
- 在 decision 里用一句话说明这些策略对后面写话术意味着什么。

## 边界
- 不推断竞品销量或份额；不点名、不贬低竞品。
