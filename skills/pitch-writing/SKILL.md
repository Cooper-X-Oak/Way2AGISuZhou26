# 怎么说（进店话术）

## 你要判断的
- 对每个目标，用什么场景切入、引用哪几条卖点、怎么讲点单机会；
- 门店所在网格的切入策略（补位 / 正面 / 避让）怎么体现在话术里。

## 工具
- `list_targets`：全部必写目标、规定的切入角度原句、可引用的卖点原文；
- `check_pitch`：用本关正式检查自查一条话术，返回是否通过和具体问题。

## 写法
- 站在店老板的角度：客人会不会点、占不占地方、成本和售价怎么核算；
- 卖点逐字引用原文，不改写、不扩写成功效；
- 必须包含规定的切入角度原句；
- 必须说明进货成本和售价需要和老板确认。

## 边界
- 不写价格、毛利、折扣、买赠、首单政策、保底利润或保证销量；
- 不写功效宣称，不点名或贬低竞品；
- 合规结果由代码扫描生成，不能自己声明「已合规」。

## 完成标准
- 每个必写目标恰好一条；
- 每条都通过 check_pitch；
- 整批交稿再过一次正式检查，有遗漏会被打回。
