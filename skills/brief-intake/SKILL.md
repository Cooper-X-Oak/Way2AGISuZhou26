# 立项

## 你要判断的
- 客户要在哪个商圈、多大范围内推广哪款产品；
- 人数、周期、每天拜访量是否给出。它们只影响排期，不影响渠道和门店分析。

## 代码负责的
- 商圈中心坐标来自商圈快照；用人数乘以每人每天拜访量得到日拜访量。

## 依据与边界
- 只记录客户说过的数字。客户没说的写 null，不要套默认值冒充客户要求；
- 「3 公里」「三公里」「3km」都换算成米；
- `questions` 只放会改变分析结果的缺口：位置、半径、产品。人数和周期未知不提问。

## 自查
- [ ] 客户原话里出现的每个数字都已转成对应字段；
- [ ] 没有把推断写成客户要求；
- [ ] questions 里没有只影响排期的问题。
