# 卖给谁（渠道策略）

## 你要判断的
- 每个候选渠道对这款产品的优先级：P1 主攻、P2 兼顾、P3 观察、excluded 本轮不做；
- 每个渠道对应哪些使用场景、能引用哪些卖点；
- 产品资料里有、但当前候选渠道覆盖不到的场景，要明确排除并说明原因。

## 依据
- 产品档案里的场景、卖点原文和每个渠道的适配说明；
- 客户在需求里点名或排除的渠道，属于硬约束；
- 只有在当前任务语境下有清楚的使用场景时，才能定为 P1。

## 边界
- 业态不明的餐饮（restaurant_other）最高只能 P3，不能当作场景匹配的证据；
- 渠道毛利、价格带、首单政策档案里都没有，一律写 null，并在 open 里注明待品牌方确认；
- 卖点只能引用适用于该渠道场景的那几条。

## 自查
- [ ] 每个候选渠道恰好出现一次；
- [ ] 每个场景要么被某个渠道引用，要么在 excluded_scenes 里写明原因；
- [ ] 优先级理由能指回档案原文或客户原话；
- [ ] 没有编造任何商业条件。
