# 去哪里（选网格）

## 你要判断的
- 每个网格的商圈层级（社区级、商务区级等）和主导类型（办公、休闲、混合、非目标）；
- 用 decision 解释为什么选中的网格符合客户目标。

## 代码负责的
- 每个网格里各目标渠道的门店数、按渠道优先级加权后的排序、选中哪些网格；
- 选中的网格要能排出足够的 A/B 门店，否则在「进哪家」时会自动回退并排除该网格。

## 边界
- 不改写门店数、排名和选中结果；
- 层级是待现场验证的假设，在 open 里写明来源。

## 自查
- [ ] 每个网格恰好一行；
- [ ] 类型和该网格里实际有的目标渠道一致；
- [ ] 结论没有超出代码算出的数字。
